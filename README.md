# Imobiliaria Design System

Design system oficial da plataforma imobiliária.

## Objetivo

Centralizar tokens, componentes, padrões, motion e documentação para:

- `imobiliaria-admin`
- `imobiliaria-front`
- produtos futuros

## Build

```bash
npm install
npm run build
npm run validate
```

Depois abra:

```text
dist/index.html
```

diretamente no navegador.
